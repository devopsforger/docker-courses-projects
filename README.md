# Docker Course Projects

Practical Docker projects and hands-on exercises for courses offered on [DevOpsForger](https://devopsforger.com).

This repository contains projects designed to help students apply what they learn, solve real engineering problems, and develop practical skills in containerization, deployment, security, networking, and troubleshooting.

The projects are organized by course, with each course providing progressively challenging exercises that reinforce the concepts taught.

## Available Courses

| Course | Description | Projects |
|---|---|---|
| [DOC-301: Docker & Containerization (Beginner)](doc-301/README.md) | Learn Docker fundamentals, build and manage containers, configure networking and storage, and deploy containerized applications. | 8 |

Additional courses and projects will be added as they become available.

## Getting Started

1. Choose a course from the table above.
2. Review its prerequisites and learning objectives.
3. Read the project instructions carefully.
4. Download any required starter applications.
5. Complete the projects independently.
6. Verify your work against the acceptance criteria.

Each course directory contains a README with its project list and instructions.

## Project Approach

Our projects are designed around practical problems rather than simply following commands.

Students are expected to understand the requirements, make technical decisions, implement solutions, test their work, and explain their approach.

Where applicable, projects use starter applications so students can concentrate on learning Docker rather than developing application code.

Reference solutions may be provided separately to support learning and self-assessment.
